# Trend research

Find current topics, sounds, and formats for the requested platform and niche.

Use the relevant `../references/<platform>.md` for exact paths and parameters. Call the REST API directly as described in `../SKILL.md`; read returned values from `data`.

1. Select supported endpoints from the platform reference. TikTok includes popular hashtags, songs, videos, creators, and a trending feed; YouTube has search and trending shorts.
2. Apply geography or date filters only when that endpoint documents them. For Instagram, search reels; for Reddit, use subreddit posts or search with documented sorting/timeframe parameters. State that these are samples rather than a complete trend ranking.
3. Inspect publication dates, captions, hashtags, and available counters. Do not infer seven-day growth from a lifetime view count or a single snapshot.
4. Summarize recurring topics and formats, source links, sample size, retrieval date, and limitations. Suggest content ideas separately from observed results.

Estimate credits from the specific calls and pages selected; avoid fetching every popular feed when one niche search answers the request.
